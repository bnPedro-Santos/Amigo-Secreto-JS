# 🎁 Amigo Secreto

Sistema web para sorteio de amigo secreto desenvolvido como desafio do programa **ONE (Oracle Next Education)**.

## 📂 Arquivos do Projeto

```
amigo-secreto/
├── index.html    # Estrutura da página
├── style.css     # Estilos visuais
├── app.js        # Lógica do sistema
└── assets/       # Imagens
```

---

## 🎯 Projeto Original (Desafio ONE)

### Funcionalidades Base:
- ✅ Adicionar nomes à lista
- ✅ Visualizar participantes
- ✅ Sortear um amigo aleatório

### Tecnologias:
- HTML5, CSS3, JavaScript

---

## 🚀 Melhorias Implementadas

Após completar o desafio original, implementei as seguintes melhorias:

### 1. **Botão de Remover**
- Botão "X" ao lado de cada nome
- Remove participantes individuais

### 2. **Tecla Enter**
- Digite o nome e pressione Enter
- Mais prático que clicar no botão

### 3. **Controle do Botão Sortear**
- Desabilitado quando há menos de 3 pessoas
- Visual indicativo quando inativo

### 4. **Sorteio Garantido**
- **Problema original**: Podia sortear a mesma pessoa várias vezes
- **Solução**: Algoritmo que garante que todos participem
- Cada pessoa recebe um amigo secreto único

### 5. **Melhor Exibição**
- Mostra todos os pares de uma vez
- Cards visuais organizados
- Botão para sortear novamente

### 6. **Validações Extras**
- Impede nomes duplicados
- Remove espaços desnecessários

---

## 🎮 Como Usar

1. **Adicionar**: Digite nomes e pressione Enter (ou clique "Adicionar")
2. **Remover**: Clique no "X" ao lado do nome
3. **Sortear**: Precisa de pelo menos 3 pessoas
4. **Resultado**: Veja todos os pares formados

## 🎓 Sobre o ONE

O **Oracle Next Education (ONE)** é um programa de educação gratuito promovido pela Oracle em parceria com a Alura, focado em formar desenvolvedores em tecnologia.

Este projeto faz parte dos desafios práticos do curso, onde aplicamos os conceitos aprendidos em projetos reais.
